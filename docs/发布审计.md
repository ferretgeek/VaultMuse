# Obsidian AI 写作助手 1.0.1 发布审计

审计日期：2026-08-09
范围：插件源码、全部可达历史与标签、依赖、构建与发布资产、交互演示、图片、文档和 GitHub 设置。

## 结论

- ESLint、55 项测试、严格 TypeScript、生产构建、发布打包与 `npm audit` 门禁通过。
- API Key 与敏感 Header 默认只在内存；路径、URL、响应、错误、持久化与发布打包的读取/校验/写入边界已加固。
- 桌面与窄屏演示、四套持久主题、深灰 `#17191d`、右上角入口和 SVG/PNG/ICO 收藏图标已验证。
- 1280×720 实际演示图与 1280×640 社交封面不含真实 Vault、账号、API 地址、密钥或图片元数据。
- Gitleaks 与 TruffleHog 对公开新鲜克隆的完整历史、全部标签及发布资产均为 0。

## 历史清理

最终复扫发现一个专门验证“拒绝 URL 内嵌凭据”的 `.example.com` 合成字符串。它不是秘密；为让外部扫描直接返回零结果，该夹具和全部可达历史已重写。不可变 `1.0.0` 标签永久退役，当前支持版本为 `1.0.1`。

旧历史 bundle、删除前 Release 元数据与资产备份仅位于 `资料/安全修复备份/`。公开分支、标签与普通全量克隆不再引用旧提交；平台对不可变发布保留的证明或缓存无法通过普通 Git 操作删除。
