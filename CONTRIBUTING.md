# Contributing / 参与贡献

Focused pull requests are welcome. 欢迎小而完整、边界清楚的改进。

1. Preserve explicit context, confirm-before-write, recoverable trash, bounded requests, memory-only secrets by default, and synthetic fixtures.
2. Do not add telemetry, remote frontend assets, hidden proxies, background whole-vault indexing, credential files, automatic deployment paths, or permanent deletion.
3. Maintain all four global themes, `#17191d` Graphite, responsive behavior, and keyboard/accessibility states.
4. Run `npm ci`, `npm run check`, `npm audit`, and `npm run package:release`.
5. Update Chinese and English docs together. Use private vulnerability reporting for security findings.
